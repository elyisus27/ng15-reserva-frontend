# CFE Analytics

Objetivo:
Visualizar y comparar consumos eléctricos históricos
de múltiples contratos CFE.

## Features actuales

- listado de contratos
- comparativa histórica
- visualización lineal
- análisis temporal

## Objetivo visual

Gráficas tipo:
- line chart
- comparación multi-serie
- tendencias históricas
- consumo mensual

## Retos actuales

- performance con múltiples contratos
- normalización temporal
- escalas visuales
- comparación clara entre contratos
